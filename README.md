# Mental Healthcare Hub

A mental wellness hub demo featuring an AI Chatbot (powered by GEMINI), Mood Tracker, and Breathing Exercises. Provides immediate support, self-care tools, and professional booking links. Built with Python/Flask and JavaScript for fast, accessible mental health resources. Disclaimer: Not a substitute for professional medical advice.

## Project Structure

```text
frontend/   Website HTML, CSS, and JavaScript files
backend/    Flask server, configuration, APIs, and data assets
```

## Run Locally

```bash
cd backend
python app.py
```

Then open `http://127.0.0.1:5000`.

On Windows, you can also double-click `OPEN_WEBSITE.bat`.

## Configuration

Copy `backend/env_example.txt` to `backend/.env` and add the required API keys. Do not commit the `.env` file.
